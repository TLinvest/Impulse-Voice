# Code of conduct

## Our standard

Impulse Voice is a technical project for people with different backgrounds,
experience levels, languages, and accessibility needs. Be respectful,
specific, and patient.

Positive participation includes:

- giving actionable technical feedback;
- assuming good intent while discussing evidence;
- welcoming questions and first-time contributors;
- respecting privacy and consent;
- focusing criticism on code, behavior, and documented trade-offs.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sexualized content, doxxing, threats, deliberate disruption, or publishing
another person's private audio, transcript, logs, or identity.

## Enforcement

Repository maintainers may edit or remove comments, commits, issues, pull
requests, discussions, and other contributions that violate this standard.
They may temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the repository owner through their GitHub
profile. Reports will be handled with discretion and conflicts of interest will
be avoided where possible.

This code of conduct applies in repository spaces and when someone is publicly
representing the project.
